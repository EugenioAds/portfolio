# Meu Portfólio

Site pessoal em HTML, CSS e JavaScript puro (sem frameworks).

## Estrutura

```
portfolio/
├── index.html      → estrutura e conteúdo do site
├── css/
│   └── style.css   → todo o estilo visual
├── js/
│   └── script.js   → pequenos comportamentos (ex: ano no rodapé)
└── images/         → coloque aqui sua foto e outras imagens
```

## Como editar

1. Abra a pasta `portfolio` no VS Code.
2. Edite os textos entre `[colchetes]` no `index.html` com suas informações.
3. Troque a foto: coloque um arquivo (ex: `foto.jpg`) dentro de `images/` e
   atualize o `src` da tag `<img class="avatar">` no `index.html` para
   `images/foto.jpg`.
4. Para ver o resultado, use a extensão **Live Server** no VS Code (clique
   direito no `index.html` → "Open with Live Server") ou simplesmente abra o
   `index.html` no navegador.
